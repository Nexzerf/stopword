# คลังคำ STOP! Word Duel

เว็บรวมคำศัพท์ภาษาอังกฤษสำหรับเกม **STOP! Word Duel** ใน Roblox

ใช้แค่ 2 แตะ:
1. เลือกหมวดที่เกมให้มา: สัตว์, อาหาร, ผลไม้, ผัก, สี, สิ่งของ, เมือง/ประเทศ, กีฬา, ชื่อคน, อาชีพ, อวัยวะ, เสื้อผ้า (หรือ "ทุกหมวด")
2. เลือกตัวอักษรขึ้นต้น A–Z

เว็บจะแสดงคำที่สั้นที่สุดตัวใหญ่ด้านบน แตะเพื่อคัดลอก คำอื่นเรียงสั้นไปยาวอยู่ข้างล่าง
บนคอมพิวเตอร์กดตัวอักษรบนคีย์บอร์ดเพื่อเลือกตัวอักษร และกด Enter เพื่อคัดลอกคำแนะนำ

เป็นไฟล์เดียว `index.html` ไม่ต้อง build เปิดในเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages
(Settings → Pages → Deploy from branch `main` / root)

แก้หรือเพิ่มคำได้ที่ตัวแปร `WORDS` ใน `index.html` (หมวด → ตัวอักษร → คำคั่นด้วยจุลภาค)
