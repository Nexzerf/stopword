# คลังคำ STOP! Word Duel

เว็บรวมคำศัพท์ภาษาอังกฤษสำหรับเกม **STOP! Word Duel** ใน Roblox แบ่งตามตัวอักษรขึ้นต้น A–Z และหมวด
Animal, Food, Color, Objects, City/Country

- เลือกตัวอักษร (หรือกดปุ่มบนคีย์บอร์ด) แล้วแตะคำเพื่อคัดลอก
- เรียงคำสั้นก่อนเพื่อพิมพ์ให้เร็ว สลับเป็น A–Z ได้
- ค้นหาคำได้ทุกตัวอักษร (`/` เพื่อค้นหา, `Esc` เพื่อล้าง)

เป็นไฟล์เดียว `index.html` ไม่ต้อง build เปิดในเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages
(Settings → Pages → Deploy from branch `main` / root)

แก้หรือเพิ่มคำได้ที่ตัวแปร `RAW` ใน `index.html`
ลำดับในแต่ละตัวอักษรคือ `[Animal, Food, Color, Objects, City/Country]` คั่นคำด้วยจุลภาค
